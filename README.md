# 国会質疑トーク（仮称）

国民民主党の国会質疑を、LINEのトーク画面のような形で1分で読める要約サイト（非公式）。
静的サイト（index.html 1ファイル）なので、レンタルサーバー不要・無料ホスティングで運用できます。

## 構成
- `index.html` … サイト本体。議員データ・要約・吹き出しはファイル内の `MEMBERS` 配列にあります。

## 公開手順（初回のみ）
1. GitHubにリポジトリを作成し、このフォルダの中身をアップロードする
2. Cloudflare Pagesでそのリポジトリを接続する（ビルド設定なし／出力はリポジトリ直下）
3. 発行された `*.pages.dev` のURLがサイトの住所になります

## 更新手順（むぎ担当・公開前チェック制）
1. 新しい文字起こしがnoteに上がる
2. むぎが `MEMBERS` に要約カード＋吹き出しを追加した更新版を用意する
3. プレビューで一美さんがチェック（数字・固有名詞・答弁の留保が重点）
4. OKが出たらGitHubへ反映 → Cloudflareが自動で本番公開する

## ルール
- 一覧のプレビューは「タイトル」ではなく「結論の一文」
- 吹き出しは1つ約100字まで。要約カードとメモを合わせて1分で全体像が分かること
- 質問（議員）／答弁（大臣・参考人）／まだ答えていない点、を混ぜない
- 議員の写真は権利が確認できたものだけ使う（当面は文字アイコン）
- 非公式であることを必ず明記する
